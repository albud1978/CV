Холст архитектуры: универсальный CV-конвейер «модели размечают → человек проверяет → student-модель обучается»

Цель: по языковому описанию объектов и видео получить проверяемый датасет, обученную модель детекции, метрики, модельную карточку и контур дообучения на новых ошибках.

Главный принцип

Не “полный автопилот”, а Human-in-the-Loop: модель быстро создает псевдоразметку, человек удаляет/исправляет критичные ошибки.

Базовый стек

Roboflow Dataset + Auto Label/Label Assist + Workflows/Inference + Python SDK/API + локальный слой подготовки видео.

Teacher-модели

Grounding DINO для open-vocabulary box, Grounded SAM/SAM для масок, CLIP/VLM для верификации/поиска спорных кадров.

Student-модели

RF-DETR / YOLO-семейство / Roboflow 3.0. Выбор зависит от точности, скорости, edge/cloud и лицензий.

Роли агентов в Cursor / MCP

cv-architect

Ведет task spec, онтологию классов, критерии приемки, структуру проекта и правила версионирования.

data-ingestion-agent

Нарезает видео, удаляет технический мусор, считает хэши, метаданные, кластеры разнообразия.

teacher-labeling-agent

Запускает foundation/teacher-модели, подбирает промпты, формирует псевдоразметку.

dataset-qa-agent

Строит очередь ручной проверки: низкая уверенность, конфликт моделей, странные bbox, дисбаланс классов.

training-agent

Создает dataset version, запускает обучение, сравнивает RF-DETR/YOLO/Roboflow-модели.

deployment-agent

Собирает Workflows, пороги, формат вывода, batch/RTSP/edge-деплой и активное обучение.
